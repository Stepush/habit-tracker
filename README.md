# Ритм / Ritm

Трекер привычек с ручным заполнением, печатным листом A4 и историей по месяцам.

## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Сервер доступен только на этом компьютере.
В режиме разработки без настройки Google данные сохраняются в localStorage.
Для входа через Google и хранения в Google Sheets используйте [инструкцию](docs/google-setup.md).
В production требуется полная конфигурация Google.

## Привычки и месяцы

- От 1 до 10 привычек: добавление, переименование, удаление и смена порядка.
- Стабильные UUID и разные цвета из пастельной палитры. Старые ID и повторяющиеся цвета преобразуются при чтении, отметки сохраняются.
- Текущий и будущие месяцы используют общий набор привычек. При сохранении настройки переносятся на уже существующие будущие месяцы; отметки сопоставляются по ID, новые привычки получают пустые строки.
- Новый месяц наследует набор привычек, но начинает с пустых отметок.
- Прошлые месяцы сохраняют собственные настройки и отметки.
- Изменения вступают в силу после нажатия «Сохранить». «Отменить» возвращает сохранённые значения.
- Выполнение: заполненная клетка — выполнено, пустая — не выполнено. Процент считается по всем клеткам месяца.
- Печатный PDF: один альбомный лист A4, клетки 7 мм, названия привычек, даты и дни недели.
- JSON: экспорт месяца или всей истории, импорт с подтверждением замены совпадающих месяцев.

## Хранение

Без Google данные привязаны к браузеру и адресу приложения. Используйте JSON для резервных копий и переноса.
С Google каждый месяц хранится в отдельном листе приватной таблицы. Облачная история находится в памяти браузера и не заменяет прежнюю localStorage-историю.
Сохранение затронутых месяцев выполняется одним запросом Sheets. Конфликт версий отклоняется; строго одновременные записи всё ещё могут конфликтовать, поскольку Sheets не поддерживает compare-and-swap.
Для облачного режима нужны сеть и предварительная настройка Google.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npm run sample:pdf -- 2026-11
```

PDF записывается в `output/pdf/`. Автотесты проверяют календарь, миграцию данных, наследование привычек, резервные копии, PDF, границы авторизации и работу с Sheets через имитацию API.
Для сквозной проверки Google нужны действующие учётные данные.

## Структура

- `src/lib/model.ts`: привычки, цвета, календарь, валидация и статистика.
- `src/lib/month-storage.ts`: загрузка месяцев и перенос набора привычек.
- `src/lib/backup.ts`: резервные копии и совместимость старых данных.
- `src/lib/pdf.ts`: печатный лист с кириллическими шрифтами.
- `src/app/tracker.tsx`: ручное заполнение, настройки и сохранение.

Лицензии шрифтов находятся в `public/fonts/`. Пакеты npm сохраняют собственные лицензии.
